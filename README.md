GROPAD WEBSITE: The Student Commerce Platform

Overview:

This is a preview of the first digital campus marketplace tailored to university students, offering a secure and centralized platform to exchange goods, services, and event opportunities.while the app is built with Flutter and powered by Supabase, the website is built with basic HMTL, CCS and Javascript to show the Gropad provides students with a safe and convenient way to engage in commerce while fostering a verified student community.
